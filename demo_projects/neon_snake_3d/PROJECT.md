# Neon Snake 3D project

Project version: **1.0.0**
Engine: **SwirEngine 1.x**
Rendering mode: **3D**

This directory is a self-contained source project for the Neon Snake 3D demo release.
The release workflow packages this directory as `NeonSnake3D-project.zip` and also builds
standalone binaries for Windows, Linux and macOS.
