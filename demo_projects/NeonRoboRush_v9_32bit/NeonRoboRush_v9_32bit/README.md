# Neon Robo Rush v9 — 32-Bit Edition

Original **32-bit console-era** platformer demo for SwirEngine 2.0.

The target look is inspired by the visual richness of late-90s 2D console/arcade games:
**Sega Saturn / 32-bit arcade / early PlayStation-era 2D**, while keeping the art original.

## v9 upgrades
- much larger, smoother **pre-rendered style robot**
- 3 idle frames
- 6 run frames
- jump / fall / hit poses
- 4-frame enemy animations
- smooth neon platforms with bevels
- three parallax background layers
- richer shadows, glows and HUD
- stable manual physics from the working v5 base
- dead-zone side-scroller camera
- absolute asset paths, so `python main.py` works directly

## Controls
- A / D or Left / Right — move
- Space / W / Up — jump
- R — restart

## Run
`python main.py`

or double-click:

`run_demo.bat`
