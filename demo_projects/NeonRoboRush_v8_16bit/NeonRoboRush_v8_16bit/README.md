# Neon Robo Rush v8 — 16-Bit Edition

Original 16-bit console-era platformer demo for SwirEngine 2.0.

## New in v8
- original **16-bit robot hero**
- idle / run / jump / fall / hit animation frames
- animated robot enemies
- pixel-art platforms
- parallax night city
- power cells, checkpoint and portal
- particles and generated SFX
- stable manual platform physics
- stable dead-zone side-scroller camera
- robust absolute asset paths: `main.py` works directly too

## Controls
- A / D or Left / Right — move
- Space / W / Up — jump
- R — restart

## Run
- `python main.py`
- or double-click `run_demo.bat`
