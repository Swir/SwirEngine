## Demo game

- Added **Neon Snake 3D**, an asset-free 3D Snake game built entirely with the public SwirEngine 1.x API.
- Added deterministic gameplay regression tests for movement, growth, reverse-direction rejection, wall collision, restart state and smoke-frame shutdown.
- Added real OpenGL/Xvfb smoke validation plus one-file Windows, Linux and macOS builds.
- Windows standalone builds explicitly bundle GLFW/glcontext and execute a packaged-runtime probe before release publication.
- This demo addition does not change the SwirEngine package version or ROADMAP completion percentage.
