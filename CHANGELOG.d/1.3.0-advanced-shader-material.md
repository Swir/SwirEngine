# Advanced Material & Shader Pipeline

- add immutable `ShaderTemplate`, explicit `ShaderHookPoint` seams and deterministic prepared `ShaderVariantSpec` keys
- add context-free `prepare_shader_variant()` so scene/material authoring does not require an active OpenGL context
- add conservative hook/define safety validation so `ShaderMesh3D` variants cannot replace the engine-owned vertex layout/version contract through the supported API
- add bounded `ShaderProgramCache` LRU compilation caching with creator-visible hit/miss/failure/eviction/invalidation diagnostics
- add `ShaderMaterial3D`, `SURFACE_3D_TEMPLATE`, `shader_material_3d()` and additive `ShaderMesh3D` production rendering without changing existing `Material3D` / Phong / PBR behavior
- share uploaded mesh vertex buffers across shader variants and cache only variant-specific VAO bindings
- integrate the shader-material pipeline into the production `ShadowedImageBasedPostProcessRenderer`, with direct directional-light support and `shader_meshes` renderer diagnostics
- add regression coverage requiring 1 backend compile plus 999 cache hits across 1,000 resolves of one prepared variant, plus one VBO/VAO for two compatible shader meshes
- add a 10,000-resolve benchmark contract, runnable creator example and real OpenGL ShaderMesh3D validation path; host timing is diagnostic only and makes no FPS claim
- document explicit current boundaries: custom shader meshes do not silently participate in auxiliary shadow-map/IBL passes and arbitrary custom sampler binding is not claimed by this milestone
