## 1.3.0 - 2026-09-15

SwirEngine 1.3.0 completes the ten-deliverable **Gameplay & Creator Power** roadmap as an additive stable-1.x release.

- Added GPU instancing and conservative frustum culling with reusable staging buffers, diagnostics and deterministic draw/cull gates.
- Added glTF skeletal animation, clip sampling/crossfades and production GPU skinning.
- Added 3D collision queries and deterministic fixed-step gameplay physics foundations.
- Added weighted deterministic 2D/3D A* navigation, route caching and navigation agents.
- Added bounded large-world chunk residency, activation/deactivation budgets and streaming hooks.
- Added controlled shader/material variants, safe custom hooks, uniforms and a bounded program cache.
- Added the 2D renderer power pass with viewport-local tilemap submission, dirty transform synchronization, conservative culling and reusable sprite staging.
- Added deterministic gameplay utilities: scheduler/timers, signals, object pools, cooldowns, spawning and `GameplayRuntime`.
- Added creator/editor integration through the existing workspace/frontend with lazy subsystem diagnostics and provider-locality guarantees.
- Added **Neon Frontier 1.3**, an asset-free integrated validation game exercising production OpenGL, GPU instancing, `ShaderMesh3D`, 3D collision queries, 3D navigation, bounded large-world streaming, gameplay scheduling, camera and lighting in one application.
- Added the strict `tools/verify_1_3_release_candidate.py --require-complete` publication contract requiring package version 1.3.0 and exactly 10/10 roadmap completion.
- Added the dedicated Full Game 1.3 gate with subsystem regressions, Ruff/compileall, real Xvfb/software-OpenGL execution and a one-file Windows PyInstaller runtime probe.
- Kept Windows x64 / CPython 3.14 native-wheel selection and import validation in the release path.
- Preserved GitHub OIDC Trusted Publishing and public-PyPI post-release metadata/install/runtime verification.
- Preserved the stable public 1.x API; 1.3 systems are additive.
- Kept performance claims tied to explicit deterministic workload counters and regression contracts rather than unmeasured FPS promises.
