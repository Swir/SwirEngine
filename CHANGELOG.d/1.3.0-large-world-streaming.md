# Large World / Chunk Streaming

- add `ChunkKey`, `ChunkDefinition`, `ChunkRegistry`, `ChunkContent` and creator build contexts for finite or procedural 2D/3D worlds
- add `LargeWorldStreamer` with local preload/active/retention windows, nearest-first bounded activation and deterministic chunk lifecycle diagnostics
- integrate chunk activation with `SceneMount` so scene objects and ECS entities unload through established lifecycle paths
- integrate declared chunk assets with `AssetStreamingManager`, including shared-asset reference-counted pinning and existing LRU residency policy
- add optional visibility gating, creator-visible failure/retry handling and bounded per-update activation/deactivation/finalization work
- add regression coverage and a benchmark contract proving candidate work stays bounded by the local chunk window rather than conceptual world size
- document current boundaries: no terrain LOD, occlusion renderer, network interest management or persistent world database is claimed by this milestone
