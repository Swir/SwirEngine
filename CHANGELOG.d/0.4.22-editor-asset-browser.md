# Visual editor asset browser model

- added public `EditorAssetBrowser`, `EditorAssetBrowserFrame` and `EditorAssetEntry` APIs
- added deterministic creator-facing asset classification for images, audio, models, fonts, data, shaders, scripts and other files
- connected editor asset metadata directly to `AssetManager` scanning, aliases, cache state and registered loaders
- added folder discovery, recursive folder filtering, text/alias search and kind filtering without loading asset contents
- added stable relative-path selection with automatic clearing when a selected file disappears
- exposed missing-alias health and aggregate file/byte diagnostics for the visual editor Assets panel
- added regression coverage for classification, filtering, alias/cache/loader metadata, selection refresh and missing aliases

This remains an additive 0.4.22-compatible editor/tooling change; the package version is intentionally unchanged.
