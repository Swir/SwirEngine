## SwirEngine 1.4 — Scene Acceleration + Occlusion

- Added conservative `VisibilityAABB3D` world bounds and a deterministic static BVH through `SceneVisibilityIndex3D`.
- Added a separate dynamic visibility layer so moving objects can refit bounds without rebuilding the static hierarchy.
- Added conservative built-in visibility bounds for `Cube3D` and `Mesh3D`, plus creator-provided `visibility_bounds` support.
- Added `visibility_dynamic` to `Cube3D` and `Mesh3D` for explicit moving-object refits.
- Added cached scene-membership synchronization through `Scene.render_objects`, preserving unsupported renderables as conservative fallback entries.
- Added `SceneAccelerationRuntime3D`, creator-facing diagnostics, `enable_scene_acceleration()` / `disable_scene_acceleration()`, and top-level public exports.
- Added opt-in `SceneAcceleratedRenderer2` integration while keeping the normal Renderer2 and stable 1.x paths unchanged.
- Added the CPU `HiZDepthPyramid3D` conservative regular-depth reference implementation with maximum-depth reduction, hole safety, depth bias, and diagnostics.
- Added `HiZPyramidPass3D`, an OpenGL 3.3 GPU maximum-depth pyramid built without CPU depth readback.
- Hardened the GPU Hi-Z pass with input-size validation, scoped framebuffer/enable-state isolation, viewport restoration, odd-dimension reduction, and a real Mesa EGL/OpenGL 3.3 smoke test.
- Added a deterministic 16,384-object visibility workload gate requiring stable work counts, a bounded leaf-test budget, and at least 98% object-test reduction for the validation layout. Host timing remains diagnostic-only.
- Removed an O(N²) visibility-index membership-counting path by maintaining static/dynamic counters incrementally during add/remove/update operations.
- Added focused regression coverage, an integration demo, strict lint/compile validation, and dedicated Scene Acceleration 1.4 CI registration.
