# 1.3.0 — 3D collision / physics foundation

- Add center-based `AABB3D` and `SphereBounds3D` gameplay bounds.
- Add live `BoxCollider3D` / `SphereCollider3D` targets with layers, masks, tags and offsets.
- Add deterministic `CollisionWorld3D` spatial hashing with box/sphere/point overlaps, finite-ray spatial candidate filtering, distance-sorted ray hits and collision-pair queries.
- Add box/box, sphere/sphere and sphere/box narrow-phase tests plus creator diagnostics.
- Add `RigidBody3D` and `PhysicsWorld3D` with dynamic/kinematic/static bodies, forces, impulses, gravity, damping, restitution, deterministic fixed substeps, catch-up caps and dropped-time diagnostics.
- Keep rigid-body response deliberately axis-aligned and box-only while sphere colliders remain available for gameplay queries; no OBB, mesh collider, CCD or full constraint solver is claimed.
- Add focused regressions, a 10,000-collider broad-phase benchmark, creator demo, documentation and dedicated CI validation.
- Preserve the published package version at 1.2.0 until the complete 1.3 roadmap passes its final release gate.
