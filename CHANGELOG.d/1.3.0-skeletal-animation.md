# SwirEngine 1.3 development — skeletal animation

- added additive `swirengine.skeletal` APIs for skeleton nodes, skins, poses, animation channels,
  clips, controllers, skinned mesh data and skinned scene objects
- added core glTF/GLB skin loading for `JOINTS_0`, `WEIGHTS_0`, inverse-bind matrices and shared node
  hierarchies without changing the existing static glTF loader contracts
- added STEP, LINEAR and CUBICSPLINE channel sampling with shortest-path quaternion SLERP and named
  clip crossfades
- added GPU skin deformation through an OpenGL 3.3 transform-feedback pre-pass feeding the existing
  forward Phong/PBR renderer
- added a texture-backed 64-joint GPU palette to avoid relying on large matrix uniform arrays
- added renderer diagnostics for skinned meshes, vertices and submitted skin joints
- added deterministic skeletal/import regression coverage, a runnable example and a real
  software-OpenGL/Xvfb GPU skinning smoke gate
- kept package version at stable `1.2.0`; no 1.3 tag, GitHub Release or PyPI publication is performed
