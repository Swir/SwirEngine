## SwirEngine 1.4 — GPU VFX + Particle Power

- Added the additive `GPUParticleEmitter3D` API and `Game.gpu_particles(...)` creator helper while keeping legacy `ParticleEmitter2D` behavior unchanged.
- Added OpenGL 3.3 transform-feedback particle simulation with ping-pong GPU buffers, deterministic ring spawning, point/box/sphere emission, gravity, drag, lifetime, seeded variation, size-over-life and color-over-life.
- Added Renderer2 GPU VFX integration before bloom with alpha/additive blending, HDR `emissive_strength`, scene-depth testing without depth writes, and render diagnostics.
- Added texture-backed sprite particles with a managed GPU texture cache.
- Added geometry-shader trails driven by current and previous positions stored in the GPU particle state.
- Added a built-in instanced mesh-particle submission path using the same transform-feedback simulation state.
- Added focused unit coverage, a real Mesa EGL/OpenGL 3.3 sprite/texture/trail/mesh smoke gate, and a capacity-independence CPU scheduling benchmark.
