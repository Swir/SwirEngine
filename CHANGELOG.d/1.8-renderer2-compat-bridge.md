### SwirEngine 1.8 — Renderer2 integration and compatibility bridge

- Added an opt-in renderer-independent bridge that converts stable 2D render runs and Renderer2 3D
  pass plans into bounded deterministic Render Graph 3.0 frame contracts before backend submission.
- Added native `render_graph18` backend dispatch, graph-validated legacy compatibility execution,
  explicit fallback/strict policies, instancing accounting and dynamic-quality frame metadata without
  changing stable 1.x renderer imports or default behavior.
- Added portable diagnostics/fingerprints, focused compatibility/failure tests, a deterministic
  64,000 logical-run workload gate, creator documentation/demo and Python 3.10/3.13/3.14 CI coverage.
