- build and clean-install a wheel on every cell, then run maintained 2D and 3D fixtures headlessly from that clean environment;

- document unclaimed architectures/interpreters and keep optional extras separate from the base-engine support claim;
- preserve frozen published 1.5.0 package metadata, including its historical roadmap URL, until the final verified 2.0 release step;
