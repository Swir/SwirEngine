# SwirEngine 1.0.0 - 2026-09-13

First stable SwirEngine release.

- declares the `swirengine.__all__` surface stable for the 1.x line and documents semantic-versioning/deprecation expectations
- synchronizes runtime and package metadata at version 1.0.0 and marks the package Production/Stable
- adds regression coverage ensuring package/runtime versions stay synchronized and every declared public export resolves uniquely
- extends CI with wheel/sdist builds, Twine metadata validation and clean-environment wheel installation/import verification
- adds a tag-driven release workflow that rejects version/tag mismatches, uploads distribution artifacts and creates the matching GitHub Release
- finalizes the 1.0 roadmap only after the complete test/lint/compile/package matrix passes
