# SwirEngine 1.7 — Background Save & Serialization I/O

- added additive `swirengine.background_save17` snapshot-first background save I/O
- capture creator-owned mappings on the owning thread into canonical immutable JSON with deterministic SHA-256 fingerprints before worker admission
- perform save writes and post-write verification through stable Save/Profile 2.0 APIs, preserving revision, integrity, atomic promotion and `.bak` recovery semantics
- reject concurrent unfinished writers to the same canonical slot path so revision discovery and backup rotation cannot race
- define an explicit cancellation cutoff before atomic commit; requests already committing refuse cancellation instead of reporting a false cancelled state after disk mutation
- add bounded diagnostics, owner-thread handoff, isolated failures, profile-manager convenience APIs, tests, creator demo, workload benchmark and Python 3.10/3.13/3.14 CI
- keep stable 1.x root imports and published 1.5.0 package metadata unchanged; Release/PyPI remain frozen until SwirEngine 2.0
