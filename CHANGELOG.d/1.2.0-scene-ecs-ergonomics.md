## SwirEngine 1.2 scene / prefab / ECS ergonomics

- Added indexed ECS component queries with deterministic diagnostics for candidate/match counts.
- Added cached ECS system ordering plus optional world lifecycle hooks.
- Added `Scene` lifecycle hooks, cached stable update snapshots and creator-visible update diagnostics.
- Added `Scene.mount()` / `SceneMount` for grouped room/chunk/encounter ownership and unload.
- Added transactional `compose_entity()` helpers that roll back partial entities on component-bundle failure.
- Added deterministic `Prefab.instantiate_many()` batch spawning with per-instance overrides.
- Added regression coverage for subclass-aware indexed queries, lifecycle ordering, mount teardown, rollback and prefab isolation.
