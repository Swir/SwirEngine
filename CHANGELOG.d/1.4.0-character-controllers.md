# SwirEngine 1.4 — Character Controllers

- Added a deterministic kinematic `CharacterController3D` built on Physics 2.0 box sweeps.
- Added grounded state, ground snapping, walkable slope limits, slope projection and bounded step-up handling.
- Added configurable acceleration, gravity, sprinting, jumping, coyote time and jump buffering.
- Added `FirstPersonController3D`, `ThirdPersonController3D` and `PlatformerController3D` gameplay presets.
- Added first-person look synchronization, smooth third-person camera rigs and third-person camera collision.
- Added `CharacterActionBindings3D` integration with the existing semantic/rebindable input layer.
- Added revision-aware `CharacterNavigationDriver3D` steering through `NavigationProvider3D` paths.
- Added per-frame character sweep/ground/step diagnostics, focused regressions, a deterministic sweep-budget gate and an integration demo.
- Kept the stable 1.x physics, camera, input and navigation APIs additive and backward-compatible.
