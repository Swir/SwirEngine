# Editor viewport picking and direct manipulation

- added public `EditorViewportController`, `ViewportRay` and `ViewportPick` APIs
- added perspective screen-to-world ray construction from `Camera3D`
- added nearest-hit 3D editor picking for visible `Mesh3D` objects using conservative transformed mesh bounds
- synchronized viewport hits and misses with the existing `SceneInspector` selection contract
- added camera-plane pointer dragging that converts pixel movement to world-space translation at object depth
- routed direct viewport manipulation through `EditorTransformGizmo`, preserving snapping and unified undo/redo history
- added regression coverage for center picking, nearest-hit ordering, misses, ray construction, drag/undo and invalid viewport dimensions

This is an additive 0.4.22-compatible editor/tooling change; the package version is intentionally unchanged.
