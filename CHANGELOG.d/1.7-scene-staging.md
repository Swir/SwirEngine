# SwirEngine 1.7 — Scene Build & Activation Staging

- Add opt-in `swirengine.scene_staging17` background scene-plan preparation on the bounded 1.7 job
  scheduler.
- Add deterministic submission-order activation with explicit per-poll main-thread work budgets.
- Add reverse transactional rollback for activation failures and cancellation, including bounded
  rollback work.
- Add stable adapters for Scene objects, Prefabs, ECS entities and `ChunkContent`/`SceneMount`
  without changing their released APIs.
- Add owner-thread enforcement, payload-free diagnostics, focused regression coverage, a creator
  demo and a deterministic staging workload benchmark.
- Keep Release/PyPI frozen until SwirEngine 2.0.
