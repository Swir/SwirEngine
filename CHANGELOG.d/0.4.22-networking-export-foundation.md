# Networking and export foundation

- Add deterministic length-prefixed JSON networking primitives with incremental decoding, a non-blocking `TCPPeer`, creator-facing `TCPClient` and pollable `TCPServer` helpers. The transport creates no background threads, so games can integrate network polling directly into their normal update loop.
- Add serializable `PackagingProfile`, `ExportTarget`, `ExportPlan`, `ExportResult` and `ProjectExporter` APIs. Desktop targets produce deterministic staging bundles plus ready-to-run PyInstaller commands; Android and Web targets produce explicitly experimental, machine-readable staging exports for external toolchains.
- Add `swirengine export` CLI support for Windows, Linux, macOS, Android and Web targets.
- Fix newly generated projects to declare the current compatible engine range (`>=0.4,<0.5`) and ignore build/dist outputs by default.
- Add regression coverage for packet framing, partial TCP reads, non-blocking peer transport, profile persistence, deterministic export plans and export manifests.
