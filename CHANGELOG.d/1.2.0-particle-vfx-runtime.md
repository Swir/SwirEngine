## SwirEngine 1.2 development — particle/VFX runtime

- Expanded `ParticleEmitter2D` with point/box/circle/ring emission regions, color and size interpolation, drag, initial rotation and angular velocity while preserving the existing 1.x constructor defaults.
- Replaced full-pool per-frame scans with a sparse active-index list and cached the renderer-facing `children` tuple, reducing Python-side update work when large pools are only partially occupied.
- Added `ParticleDiagnostics` counters for live capacity, total emissions, pool recycling, per-frame update visits and last spawn count.
- Added deterministic regression coverage, creator documentation and a runnable VFX demo.

Release/PyPI remains frozen until the active 1.2 roadmap reaches a verified 10/10 = 100%.
