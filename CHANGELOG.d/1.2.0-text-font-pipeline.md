## SwirEngine 1.2 development — text/font pipeline

- Added `FontAsset`, `FontFamily` and `FontRegistry` for explicit project font assets and ordered fallback families.
- Added cached `TextLayoutEngine` wrapping, explicit newline preservation, left/center/right alignment and long-word splitting.
- Added immutable layout/run results that materialize directly into existing renderer-native `Text2D` objects without breaking the 1.x primitive API.
- Added deterministic `TextLayoutDiagnostics` for requests, cache hits/misses, LRU evictions, measurement work and fallback switches.
- Added regression coverage proving that 1,000 identical repeated layout requests perform zero additional measurement work after the first cached layout.
- Added creator documentation and a runnable text-layout example.

Release/PyPI remains frozen until the active 1.2 roadmap reaches a verified 10/10 = 100%.
