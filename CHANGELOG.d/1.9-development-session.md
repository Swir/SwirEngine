# SwirEngine 1.9 — unified development session

Source-only development toward SwirEngine 2.0.

- Adds optional manifest-owned `[run]` configuration with a backwards-compatible default.
- Adds deterministic run plans with bounded arguments/environment overrides and portable fingerprints.
- Adds `swirengine run`, dry-run diagnostics, safe literal argument forwarding and explicit host
  environment inheritance controls without shell execution or global environment mutation.
- New 2D/3D projects include an immediately runnable development configuration.
- Adds focused process/CLI/integration tests, creator documentation, a bounded run-plan workload and a
  Python 3.10/3.13/3.14 CI gate.
- No release tag, GitHub Release or PyPI publication is created for 1.9.
