# SwirEngine 1.9 — unified development run sessions

Source-only development toward SwirEngine 2.0.

- Adds manifest-driven `swirengine run` for both 2D and 3D projects with an inspectable dry-run path.
- Adds bounded `[run]` configuration for entrypoints, project-contained working directories, arguments
  and explicit child-process environment values while preserving safe defaults for legacy manifests.
- Adds immutable portable run plans with deterministic fingerprints and no mutation of global
  `os.environ`.
- Forwards creator arguments without a shell, propagates game exit codes and reports actionable
  startup diagnostics separately from packaging-only failures.
- Adds focused/hardening tests, a 5,000-plan workload, creator documentation and a dedicated
  Python 3.10/3.13/3.14 validation gate.
- No release tag, GitHub Release or PyPI publication is created for 1.9.
