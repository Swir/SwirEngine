# SwirEngine 1.7 — Shared Resource Budget Broker

- Added additive three-dimensional resource accounting for memory bytes, resident counts and creator-defined work units.
- Added deterministic pressure admission and eviction: lower priority first, newest-first tie breaking, non-evictable protection and atomic no-partial-change rejection.
- Added creator reservation classes that protect resident usage floors while allowing unused capacity to be borrowed.
- Added per-subsystem hard limits so one streaming subsystem cannot silently consume another subsystem's allocation.
- Added side-effect-free two-phase admission plans with revision-based stale-plan rejection plus one-call atomic admission.
- Added payload-free pressure diagnostics, stable rejection reasons and exact admission/release/eviction counters.
- Added focused regression tests, creator documentation/demo and a deterministic 5,000-admission pressure workload.
- Kept stable 1.x public APIs and package metadata unchanged. Release/PyPI remain frozen until SwirEngine 2.0.
