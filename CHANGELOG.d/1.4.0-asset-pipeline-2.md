## Asset Pipeline 2.0

- added a bounded background `AssetPipeline` with dependency-aware processor registration;
- added SHA-256 `AssetFingerprint` validation and transactional stale-import rejection;
- added transitive `AssetDependencyGraph` invalidation integrated with `AssetManager` invalidators and filesystem-driven hot reload;
- preserved the existing `AssetPreloader` API and behavior;
- added dependency-aware glTF/GLB pipeline registration and external buffer/image discovery;
- expanded glTF PBR material preservation with `MASK`/`BLEND`, `alphaCutoff` and `doubleSided` metadata while keeping unsupported texture transforms explicit;
- added conservative mesh optimization with opt-in glTF degenerate-triangle cleanup;
- added opt-in PNG/JPEG/WebP texture resizing/re-encoding with before/after diagnostics and no destructive source rewrite;
- added a persistent content-addressed `DerivedAssetCache` for bytes/JSON artifacts with atomic writes and storage budgets;
- exposed the Asset Pipeline 2.0 runtime, cache and glTF registration APIs from the top-level package;
- added focused race, cache, dependency, optimization, glTF and integration regression coverage;
- added a deterministic Asset Pipeline 2.0 cold/warm/invalidate/refill workload gate and integration demo.
