## Asset Pipeline 2.0

- added a bounded background `AssetPipeline` with dependency-aware processor registration;
- added SHA-256 `AssetFingerprint` validation and transactional stale-import rejection;
- added transitive `AssetDependencyGraph` invalidation integrated with `AssetManager` invalidators;
- preserved the existing `AssetPreloader` API and behavior;
- added dependency-aware glTF/GLB pipeline registration and external buffer/image discovery;
- added a persistent content-addressed `DerivedAssetCache` for bytes/JSON artifacts with atomic writes and storage budgets;
- added focused race, cache, dependency, glTF and integration regression coverage;
- added a deterministic Asset Pipeline 2.0 workload gate and integration demo.
