## 1.2.0 - 2026-09-14

SwirEngine 1.2.0 completes the ten-deliverable 1.2 roadmap as an additive stable-1.x upgrade focused on complete game-production systems, lower Python-side frame work and verified shipping workflows.

- added sparse pooled particle/VFX updates, spawn shapes, lifecycle curves and deterministic diagnostics
- added font assets, fallback families, wrapping/alignment layout and bounded text-layout cache diagnostics
- added shared 2D/3D camera rigs with bounds, dead-zone follow, smoothing, rails and deterministic shake
- added typed settings, deterministic migrations, profile/save-slot layout and stronger atomic writes
- added gameplay messages, explicit RPC registration, connection state and deterministic networking diagnostics
- added scene lifecycle hooks, grouped mounts, indexed ECS queries, cached system/update ordering and deterministic prefab batch spawning
- added budgeted staged asset streaming with nonblocking finalization, deterministic LRU residency, pinning, eviction and hitch diagnostics
- reduced renderer/VFX Python-side frame work with streamed 2D render runs, bounded batch-state reuse and allocation-reduction regression gates
- added verified native desktop export with deterministic manifest v2, generated PyInstaller spec and one-file/one-directory runtime smoke on Windows, Linux and macOS
- added a dedicated 1.2 release-contract verifier covering roadmap math, package metadata, Python support, public API anchors, creator documentation, complete demos and publication workflow safety
- switched normal CI from the historical 1.1 contract to the active 1.2 contract while keeping historical roadmaps immutable
- removed stale hard-coded 1.1 wheel assertions from Windows CPython 3.14 CI and made the native-wheel checks follow package metadata
- hardened publication to require exact 10/10 completion, final version 1.2.0 and GitHub OIDC Trusted Publishing without `skip-existing`
- added post-release verification that waits for public PyPI metadata, installs the public `swirengine==1.2.0` artifact, validates version/core API, runs Neon Cube Hunt 3D on Linux and probes Neon Snake 3D on Windows CPython 3.14
- preserved the stable 1.x creator surface; the 1.2 systems are additive and existing projects are not forced to adopt them
- kept performance claims tied to explicit workload/regression tests rather than unmeasured FPS promises

The canonical historical changelog remains in `CHANGELOG.md`; this release note is the complete final 1.2.0 release entry used by the 1.2 publication contract.
