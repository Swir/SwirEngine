## Camera systems

- Add additive `CameraRig2D` and `CameraRig3D` workflows around the stable 1.x camera classes.
- Add time-step-aware exponential follow smoothing, 2D dead zones and bounded 2D/3D logical positions.
- Add deterministic multi-segment `CameraRail2D` / `CameraRail3D` paths for scripted shots and transitions.
- Add deterministic decaying camera shake without per-frame random sampling or allocations.
- Preserve `Camera3D` view direction while rig movement, rails and shake translate the camera.
- Add regression coverage, documentation and a runnable camera workflow demo.
