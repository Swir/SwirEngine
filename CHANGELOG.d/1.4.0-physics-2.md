## SwirEngine 1.4 — Physics 2.0

- Added additive `PhysicsScene3D` / `PhysicsBody3D` APIs while preserving the existing 1.x `PhysicsWorld3D` behavior.
- Added deterministic box-box, sphere-sphere and sphere-box contact generation.
- Added penetration correction, restitution and friction impulse response.
- Added box/sphere shape sweeps and optional continuous-body motion to prevent the validated thin-wall tunneling case.
- Added bounded distance-joint solving with stiffness and damping.
- Added configurable body sleeping/wake behavior and physics diagnostics.
- Added a backend-ready `PhysicsBackend3D` protocol.
- Reworked Physics 2.0 broad phase to build one shared spatial hash per fixed substep instead of rebuilding per moving body.
- Added focused regression coverage, a sparse broad-phase/CCD performance gate, demo and dedicated CI validation.

Benchmark timings remain diagnostic only; no unmeasured FPS improvement is claimed.
