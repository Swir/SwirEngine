# Visual editor transform gizmos

- added public `EditorTransformGizmo`, `GizmoTransformSnapshot` and `GizmoApplyResult` APIs
- added toolkit-agnostic Move/Rotate/Scale editing for existing 3D `Vec3` transforms
- added 2D translation/rotation support for the current `x`/`y` + scalar rotation convention
- added uniform scaling support for scalar `scale`/`size` targets such as `Cube3D`
- added viewport-driven gizmo mode and translation/rotation/scale snapping integration
- routed gizmo mutations through `SceneInspector` so normal undo/redo and stale-target safety remain authoritative
- added regression coverage for 2D/3D transforms, snapping, validation and undo/redo

This is an additive 0.4.22-compatible visual-editor tooling change; the package version remains unchanged.
