# 1.2 build / export hardening

- Added explicit host-native Windows, Linux and macOS desktop builds through `ProjectExporter.build_native()` while preserving staging-only export as the default behavior.
- Added portable generated PyInstaller specs for one-file and one-directory shipping, including staged assets, scenes and dynamically loaded project scripts.
- Added export-manifest format v2 with deterministic staged inputs, SHA-256 integrity hashes and native-spec metadata.
- Added path hardening for entrypoints, include paths and icons so export profiles cannot escape the project root.
- Added `NativeBuildResult` / `NativeBuildError` and CLI `--build-native` without breaking existing 1.x export calls.
- Added real executable shipping smoke verification on Windows, Linux and macOS: CI builds both one-file and one-directory artifacts, launches them and verifies packaged resources plus SwirEngine import.
- Android and Web remain explicitly experimental staging targets; no production shipping support is claimed for them in 1.2.
