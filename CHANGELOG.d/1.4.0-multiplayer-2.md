# SwirEngine 1.4 Multiplayer 2.0

- added opt-in `swirengine.multiplayer14` replicated component schemas with portable value validation
- added canonical authoritative world snapshots and sparse entity-level snapshot deltas with baseline validation
- added bounded out-of-order snapshot buffering and schema-aware numeric interpolation
- added deterministic client-side prediction with bounded input history, authoritative reconciliation and replay
- added bounded authoritative rewind history as the server-side lag-compensation foundation
- added deterministic global/per-channel bandwidth accounting without hidden wall-clock reads
- added an additive `NetworkPacket` bridge for snapshot and delta transport without changing stable 1.x networking APIs
- added focused deterministic regressions, legacy networking compatibility coverage, a 500-entity workload benchmark, documentation, demo and a dedicated Python 3.10/3.13/3.14 validation gate

The package version and stable release remain 1.3.0. Roadmap completion may advance only after the
complete Multiplayer 2.0 milestone and repository regression matrix are verified green; no 1.4 tag
or release is permitted before 10/10.
