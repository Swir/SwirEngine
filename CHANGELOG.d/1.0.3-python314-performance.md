# SwirEngine 1.0.3 — Python 3.14 and smoother frame workloads

- add fully verified Windows x86-64 CPython 3.14 support while retaining Python 3.10-3.13 across Windows, Linux and macOS
- add a dedicated Windows x86-64 CPython 3.14 SwirEngine wheel containing verified private builds of ModernGL 5.12.0 and glcontext 3.0.0, avoiding end-user MSVC compilation
- build, install and import the CPython 3.14 native renderer wheel in clean GitHub Actions environments before PyPI publication
- expand the main CI matrix with Windows Python 3.14 while preserving the full cross-platform Python 3.10-3.13 matrix
- prove that normal pip candidate selection prefers the native `cp314-cp314-win_amd64` wheel over the universal wheel on Python 3.14
- add reproducible native-wheel vendoring with license preservation, platform tags and regenerated wheel RECORD metadata
- reduce steady-state 2D batching overhead with a bounded canonical texture-path cache and single-pass render-run construction
- reduce repeated 3D CPU transform work with a bounded matrix cache while preserving independent mutable return values
- add regression tests for batching order, path-cache reuse, transform-cache semantics and platform-wheel construction
- refresh README/PyPI documentation for Python 3.14 installation and the 1.0.3 performance work
- keep the completed 1.0 roadmap unchanged at 31/31 (100%) because this is a stable-line compatibility/performance patch
