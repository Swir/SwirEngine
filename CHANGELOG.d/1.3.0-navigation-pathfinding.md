# 1.3.0 — Navigation & pathfinding

- Add deterministic weighted A* navigation for 2D grids and 3D XZ navigation planes.
- Add blocked cells, weighted traversal costs, diagonal movement and corner-cutting control.
- Add bounded revision-aware route caching so repeated stable queries avoid repeated A* expansion.
- Add dynamic obstacle/cost revisions with automatic agent repathing.
- Add `NavigationAgent2D` and `NavigationAgent3D` distance-budget path followers.
- Add `NavigationProvider2D` / `NavigationProvider3D` compatibility contracts as the route toward future authored/generated navmesh backends.
- Add deterministic regression coverage, creator documentation, runnable demo and a host-diagnostic benchmark.
- Keep the published package version at 1.2.0 until the full 1.3 roadmap is complete and release-verified.
