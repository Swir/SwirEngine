## Added

- Added `PostProcessSettings` and `PostProcessRenderer` for an optional GPU full-screen post-processing pass.
- Added creator-facing ACES/Reinhard tone mapping, exposure, gamma, contrast, saturation, vignette and FXAA controls.
- Added `Game.configure_postprocess(...)`; the normal renderer path remains unchanged while post-processing is disabled.
- Added validation that applies multi-field settings atomically and rejects unknown or invalid values.
- Added a runnable `examples/demo_postprocess.py` scene and regression coverage for the public configuration API.

## Compatibility

The feature is additive in 0.4.22. Existing games keep post-processing disabled by default, so their rendering behavior and creator-facing API remain compatible.
