# SwirEngine 1.0.2

- synchronize `swirengine.__version__` with package metadata and restore the release-contract CI invariant
- update generated project metadata from the obsolete `>=0.4,<0.5` range to the stable `>=1.0,<2.0` line
- refresh README/PyPI documentation to describe the completed 1.0 renderer, editor, networking/export features and current Python support accurately
- add regression coverage that keeps package metadata, README release information and generated project compatibility in sync
- harden the PyPI release workflow so pytest, Ruff and compileall must pass before distributions can be published
