# SwirEngine 1.7 — Async Asset Decode/Cook Pipeline

- Added the additive `swirengine.assets17.AsyncAssetPipeline` on top of the bounded 1.7 job scheduler.
- Added worker-thread file fingerprinting, dependency discovery, decode/cook stages and derived-request dependency gating.
- Added explicit bounded owning-thread finalization for GPU/audio/thread-affine resource creation.
- Added cooperative cancellation through the worker-to-finalizer handoff and stale-build refusal when source/dependency inputs change.
- Added CPU-product caching with exact finalized hit/miss diagnostics, scoped invalidation and no caching of failed/cancelled/stale products.
- Added focused regression tests, creator documentation/demo and a 1,024-request workload benchmark.
- Kept published 1.x asset APIs and package metadata unchanged. Release/PyPI remain frozen until SwirEngine 2.0.
