# Advanced Gameplay Framework

- add `swirengine.gameplay` with deterministic `Scheduler`, cancellable `TimerHandle`, `Signal`, `SignalConnection`, `ObjectPool`, `Cooldown`, `Spawner` and `GameplayRuntime`
- keep the existing `EventBus`, `Game.update` and `Game.fixed_update` contracts unchanged; the new runtime composes through the public update callback API
- use a min-heap for timers so updates with no due callbacks do not scan the full timer registry
- define deterministic equal-deadline callback ordering and non-bursting repeating-timer rescheduling after long frames
- add ordered mutation-safe signals with one-shot subscriptions and explicit connection ownership
- add prewarmed/bounded object pools with lifecycle hooks and reuse diagnostics
- add clock-backed cooldowns that require no per-frame registration or scanning
- add scheduler-backed spawners with immediate start, stop, burst, limits and a spawned signal
- add regressions, benchmark, runnable creator example and focused documentation
- performance contract: 10,000 dormant timers across 1,000 idle updates must produce zero heap pops; a prewarmed 5,000-object pool must complete five full reuse cycles without additional factory calls
- host timings are diagnostic only and do not imply an FPS uplift
