## SwirEngine 1.2 save/config expansion

- Keep the stable 1.x `SaveStore` API and plain JSON on-disk format while strengthening its atomic writer with unique same-directory temporary files, flush + `fsync`, and `os.replace`.
- Add `SettingSpec` and `SettingsSchema` for typed defaults, choices, numeric ranges and deterministic unknown-key handling.
- Add versioned `SettingsStore` envelopes with future-version protection, reset/update helpers and storage diagnostics.
- Add explicit one-version-at-a-time `MigrationRegistry` transforms that run before current-schema validation.
- Add `ProfileStore` / `ProfilePaths` with traversal-safe profile and slot names, separate settings and save-slot files, deterministic slot discovery and a cloud-sync-friendly directory layout.
- Add regression coverage, focused documentation and `examples/demo_save_config.py`.
