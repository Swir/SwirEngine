# Project-level editor workspace shell

- added versioned `EditorProjectState` persistence for editor-only project metadata without changing runtime scene serialization
- added per-scene `EditorSceneState` snapshots that combine portable hierarchy/selection state with viewport preferences
- added validated `EditorPanelState` layout metadata and a canonical default layout for hierarchy, viewport, inspector, assets, console and profiler panels
- added `EditorViewportState` for 2D/3D mode, gizmo mode, grid visibility and translation/rotation/scale snapping preferences
- added `EditorWorkspace` as the GUI-agnostic visual-editor shell model coordinating scene inspection, selection, filters, undo/redo, panel layout, viewport state, scene switching and project capture/restore
- added immutable `EditorShellFrame` view-model snapshots so future native/web/in-game editor front-ends can render a stable shared contract
- added JSON string/file round-tripping for project state plus transactional active-scene restoration
- added regression coverage for persistence, shell frames, scene switching, filters, panel/viewport validation and failed restore safety
- added `examples/demo_editor_workspace.py`

This remains an additive 0.4.22-compatible architecture/tooling change; the package version is intentionally unchanged.
