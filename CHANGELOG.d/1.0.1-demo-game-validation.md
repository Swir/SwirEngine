# SwirEngine 1.0.1 — real 3D validation and runtime fixes

- added `demo_projects/neon_cube_hunt_3d`, an asset-free playable 3D game built only from the stable public SwirEngine 1.x API
- added deterministic tests covering game construction, movement, collectibles, hazards, round reset behavior, and smoke-frame shutdown
- added a real OpenGL/Xvfb smoke job so CI boots the game through the production `Game.run()` path and renders multiple frames instead of validating imports alone
- added cross-platform PyInstaller demo bundles plus automated GitHub Releases for both SwirEngine package artifacts and the complete Neon Cube Hunt 3D project
- fixed the IBL GLSL shader using the reserved identifier `packed`, which Mesa correctly rejected on a real OpenGL driver
- fixed shadow/IBL passes assuming ModernGL depth state properties were readable; real contexts may expose write-only state getters that raise `NotImplementedError`
- added a regression test for write-only ModernGL context state and kept the public 1.x API fully compatible

The engine patch version is 1.0.1 because the end-to-end game validation uncovered and fixed real runtime defects in 1.0.0.
