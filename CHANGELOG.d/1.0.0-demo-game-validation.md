# Official 3D game validation project

- added `demo_projects/neon_cube_hunt_3d`, an asset-free playable 3D game built only from the
  stable public SwirEngine 1.x API
- added deterministic tests covering game construction, movement, collectibles, hazards, round
  reset behavior, and smoke-frame shutdown
- added a real OpenGL/Xvfb smoke job so CI boots the game through the production `Game.run()` path
  and renders multiple frames instead of validating imports alone
- added cross-platform PyInstaller demo bundles plus automated GitHub Releases for both the
  SwirEngine 1.0 package artifacts and the complete Neon Cube Hunt 3D project
- kept the engine package at 1.0.0 because this is release validation/sample coverage rather than an
  API or runtime behavior change
