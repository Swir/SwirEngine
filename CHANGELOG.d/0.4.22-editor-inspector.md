# Editor hierarchy/inspector foundation

- added public `SceneInspector`, `HierarchyItem`, `InspectorField`, `InspectorSnapshot` and `PropertyEdit` APIs
- added one hierarchy model spanning classic scene objects and ECS entities
- added runtime-stable selection keys that survive scene insertion/removal/reordering
- added query, tag and disabled-state hierarchy filters for editor search surfaces
- added immutable inspector snapshots exposing public object/entity state and ECS component type summaries
- added bounded reversible property-edit history with undo/redo and stale-target protection
- added ECS component field snapshots and direct component property editing through the same inspector contract
- component edits reuse stable entity keys, participate in bounded undo/redo history and safely detect removed components
- added editor-only hierarchy parenting across classic objects and ECS entities without mutating runtime transforms
- added deterministic sibling reordering, indexed reparenting, parent/depth/order row metadata and cycle prevention
- stale parent removal now promotes surviving children to roots so the editor tree stays valid as scenes change
- added regression coverage plus `examples/demo_scene_inspector.py`
- advanced the architecture roadmap toward structural undo/redo and persistent visual-editor hierarchy state

This is an unreleased 0.4.22-compatible architecture hardening change; the package version is intentionally unchanged.
