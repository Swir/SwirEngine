# PBR material channel model

- Extended `Material3D` with normal, occlusion and emissive texture slots plus glTF-style scalar controls (`normal_scale`, `occlusion_strength`) and emissive RGB factor storage.
- Kept the change additive and backwards-compatible: legacy Phong-only materials retain their previous behavior, while extended channels opt into the existing PBR path.
- Added strict validation for invalid normal scale, occlusion strength and negative emissive factors.
- Added regression coverage proving map paths are preserved without eagerly loading image data.

This is a foundation step toward the remaining 0.4 color-space/PBR hardening deliverable; renderer sampling and glTF import/export coverage for these channels are intentionally still tracked as unfinished work, so roadmap progress is not advanced by this change.
