# SwirEngine 1.7 — Frame-time Budget Controller

- added additive `swirengine.frame_budget17` owning-thread work metering without changing the stable 1.x game loop or profiler APIs
- bound async/finalization handoff by explicit per-frame time, item and drain-call budgets
- added deterministic priority scheduling, equal-priority rotation and best-effort reserved work so tight frames do not permanently starve peer or low-priority lanes
- isolated creator drain failures and invalid return counts while allowing later lanes to continue in the same frame
- added owner-thread/reentrancy guards, bounded lane registration/configuration and per-lane/global diagnostics with no creator payload capture
- integrated numeric budget diagnostics with the additive `PerformanceDiagnostics2` provider surface
- added focused tests, creator demo, deterministic 10,000-frame workload benchmark and Python 3.10/3.13/3.14 CI coverage
- keep stable 1.x root imports and published 1.5.0 package metadata unchanged; Release/PyPI remain frozen until SwirEngine 2.0
