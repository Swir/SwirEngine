### Added

- Added `EditorFrontendController` and immutable `EditorFrontendFrame` snapshots that combine `EditorWorkspace`, hierarchy/inspector state, optional asset browsing, console output and profiler metrics behind one interactive front-end contract.
- Added a built-in Tkinter desktop editor (`TkEditorApp`) with hierarchy search/selection, inspector property editing, shared Undo/Redo, gizmo and snap controls, asset browsing, console and profiler panels. Tkinter is imported lazily so headless/runtime users keep the existing dependency profile.
- Added safe, type-aware inspector text parsing through `parse_editor_value` using `ast.literal_eval` for containers instead of evaluating arbitrary code.
- Added `examples/demo_visual_editor.py` plus regression coverage for selection, editing, history, filtering, viewport controls and optional editor services.

### Notes

- The desktop shell is now a real interactive visual front-end for the editor models. Embedding the live renderer framebuffer and deeper play/edit runtime synchronization remain part of the separate tighter editor/runtime integration milestone.
