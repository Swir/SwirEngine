# Visual editor console and profiler models

- added public `EditorConsole`, `EditorConsoleEntry` and `EditorConsoleFrame` APIs
- added bounded, thread-safe editor log history with monotonic sequence IDs
- added level/source/query filtering, severity counts, recent-entry limits and clearing
- added reusable standard-library `logging.Handler` integration without coupling to a GUI toolkit
- added public `EditorProfiler` and `EditorProfilerFrame` views over the existing runtime `Profiler`
- added rolling-window averages, frame/CPU peaks, minimum FPS and configurable frame-budget health
- added regression coverage and `examples/demo_editor_diagnostics.py`
- advanced the visual-editor roadmap so Console/Profiler data models are no longer blockers

This remains an additive 0.4.22-compatible tooling change; the package version is intentionally unchanged.
