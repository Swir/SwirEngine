# SwirEngine 1.3 — GPU instancing and frustum culling

- adds additive `Instance3D`, `InstancedMesh3D`, `InstancedCube3D` and `Frustum3D` APIs
- adds real ModernGL per-instance vertex attributes and one instanced draw per visible batch
- adds conservative CPU sphere/frustum rejection before GPU submission
- reuses a grow-on-demand float32 staging buffer and packs transforms directly without allocating one standalone transform matrix per instance
- carries per-instance RGBA variation while retaining `Material3D` tint/material channels
- supports the direct forward Phong/PBR path with base, metallic/roughness, normal, occlusion and emissive texture channels plus directional/point/spot lights
- extends `RendererStats` with submitted instances, instance batches, candidates and culled count
- adds deterministic regression coverage, a 10,000-instance CPU cull/pack benchmark framework, creator documentation and `examples/demo_gpu_instancing.py`
- starts `ROADMAP_1_3.md` without changing the published package version or releasing to PyPI
