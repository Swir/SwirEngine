# SwirEngine 1.4 editor authoring power

- added ordered multi-selection with replace/add/toggle/range selection while mirroring one primary target into the stable 1.x inspector contract
- added grouped multi-target property, transform-gizmo and asset-path authoring with one logical undo/redo transaction and preflight protection against partial edits
- added persistent portable multi-selection through an additive `swirengine.editor_authoring` project sidecar without changing hierarchy format v1
- added safe drag-and-drop asset payloads with project-relative path validation across POSIX, Windows drive-qualified and UNC forms
- added indexed live-key selection lookup plus a dedicated 500-target selection/edit/undo/redo performance contract
- added toolkit-neutral material, physics and navigation inspector adapters with explicit mixed-value snapshots, validation and component-aware history
- added `EditorAuthoringPlayController` to lock creator mutations during Play, verify edit-scene/history isolation and restore portable selection on Stop
- added the opt-in `swirengine.editor14` facade as the supported creator-facing 1.4 authoring import surface while preserving stable 1.x imports
- added focused documentation, integration demos and the dedicated Editor Authoring 1.4 CI gate

Milestone completion is verified by the dedicated authoring regression/Ruff/compile/demo/benchmark gate and the full compatibility matrix. The package version and stable release remain 1.3.0 until the complete 1.4 roadmap reaches 10/10.
