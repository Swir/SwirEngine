# SwirEngine 1.4.0 — integrated showcase and release gate

- Added a deterministic production showcase that exercises Terrain + World LOD, bounded large-world streaming, Physics 2.0 character movement, Renderer 2.0 configuration, GPU VFX scheduling, Editor Authoring Power and Multiplayer 2.0 snapshot/delta paths in one creator-facing scenario.
- Added a real Mesa/OpenGL 3.3 Xvfb showcase smoke alongside the dedicated Renderer2, GPU particle and Hi-Z execution gates.
- Added focused showcase regression coverage and a release-readiness contract that requires the showcase code, documentation and test to land together.
- Expanded the non-publishing 1.4 readiness matrix across focused regressions, all nine 1.4 performance contracts, headless integration demos, real OpenGL smokes, package metadata, clean-wheel installation and compatibility checks.
- Hardened the publication workflow so a future 1.4 release must pass the strict 10/10 verifier, the complete regression suite, stable 1.x compatibility workloads, all 1.4 performance contracts, integrated showcase execution, real OpenGL validation, Windows one-file packaging and the native CPython 3.14 wheel path before PyPI or GitHub Release publication can begin.

Publication remains explicitly guarded; this changelog entry does not by itself mark the roadmap complete or publish any artifact.
