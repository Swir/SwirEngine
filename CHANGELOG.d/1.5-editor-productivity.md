# SwirEngine 1.5 — Editor Productivity 2.0

- Add opt-in `swirengine.editor15` prefab authoring documents with deterministic
  diff/apply/revert workflows that preserve internal prefab references without
  mutating the released stable source `Prefab`.
- Add materialized prefab variants that export as ordinary stable prefabs.
- Add bounded shared creator command history and previewable, stale-safe,
  rollback-capable atomic batch property editing.
- Add project asset-reference auditing for missing, unsafe and unused creator
  assets plus broken aliases without loading asset contents.
- Add focused tests, a headless creator demo, a measurable workload benchmark,
  documentation and a Python 3.10/3.13/3.14 validation workflow.
