## Responsive UI layout and navigation

- added viewport anchors for center, edges and corners,
- added reference-resolution UI scaling with min/max clamps,
- added vertical and horizontal containers that preserve creator order and avoid compounded resize scaling,
- integrated responsive containers directly with `UIManager` so layouts follow the live viewport automatically,
- scaled button/label text alongside control geometry and resynchronized panels/progress bars after layout changes,
- added deterministic keyboard/gamepad focus navigation with wrapping and disabled/hidden/non-focusable control skipping,
- added keyboard Enter/Space and standardized gamepad A activation plus mouse-to-focus handoff,
- exposed the responsive UI/focus API from top-level `swirengine`,
- documented the integrated workflow, added a complete responsive menu example and expanded regression coverage for resize, geometry, focus and activation.

This is a SwirEngine 1.1 development milestone only. Release/PyPI remains frozen until the complete 1.1 roadmap is verified at 100%.
