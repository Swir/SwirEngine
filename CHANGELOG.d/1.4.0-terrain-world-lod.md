## SwirEngine 1.4 — Terrain + World LOD

- Added immutable heightmap terrain storage with bilinear world-space height and normal sampling.
- Added deterministic chunk mesh generation with multiple distance-based LOD strides and edge-safe coarse sampling.
- Added bounded LRU caching for `(terrain chunk, LOD)` meshes plus build/cache/selection diagnostics.
- Added normalized multi-layer terrain splat maps and creator-facing terrain material metadata.
- Added `TerrainCollider3D` ground-height, normal, downward-ray and snap-to-ground queries.
- Added `TerrainChunkProvider` and aligned Large World settings so terrain chunks can use the existing residency/mount lifecycle.
- Added an asset-free integration demo, focused regression suite and deterministic local-window/LOD performance gate.

Host benchmark timings remain diagnostic only; no FPS improvement is claimed without direct measurement.
