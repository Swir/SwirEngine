# SwirEngine 1.9 — project production manifest foundation

Source-only development toward SwirEngine 2.0.

- Adds a validated, deterministic `swirproject.toml` production contract with compatibility for
  earlier minimal root-key manifests.
- Adds safe named packaging profiles that map onto the existing `PackagingProfile` exporter contract.
- Adds `swirengine doctor` for non-mutating project/profile readiness checks.
- Adds `swirengine export --profile NAME` while preserving explicit `--target` export.
- New projects now receive Windows/Linux/macOS production profiles.
- Adds path traversal/absolute-path rejection, deterministic manifest fingerprints, focused tests,
  creator documentation, a bounded workload benchmark and a Python 3.10/3.13/3.14 CI gate.
- No release tag, GitHub Release or PyPI publication is created for 1.9.
