# Expanded audio mixer

- Added creator-facing audio buses/groups with custom gain and mute controls while preserving the existing `master_volume`, `sound_volume` and `music_volume` API.
- Added deterministic handle fades (`fade_to`, `fade_in`, `fade_out`) advanced through `AudioEngine.update(dt)`, including optional stop-on-fade and music fade-out support.
- Added listener/source spatial controls with distance attenuation and optional stereo panning on capable backends.
- Added runtime `AudioDiagnostics` snapshots for active, music, spatial and fading handle counts plus bus/mute state.
- Kept custom 1.x backends compatible: stereo output is optional and discovered dynamically through `set_stereo`.
- Extended audio regression coverage for bus composition, mute behavior, deterministic fades, spatial attenuation/pan and diagnostics.
