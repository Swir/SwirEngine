## Editor runtime integration

- added public `EditorRuntimeSession`, `EditorRuntimeMode` and immutable `EditorRuntimeFrame`
- entering Play mode clones the current edit scene through the configured `SceneSerializer`, keeping runtime mutations isolated from authoring state
- added pause/resume, deterministic fixed-step preview updates and single-frame stepping while paused
- stopping Play mode discards preview state and immediately returns the original edit scene
- added start/stop lifecycle callbacks plus safe edit-scene replacement when no preview is active
- custom serializer registries are supported so project-defined scene objects and ECS components can participate in Play mode
- added regression coverage and a runnable `demo_editor_runtime.py` example
- this is the Play/Edit synchronization foundation for the still-open tighter editor/runtime integration roadmap deliverable; embedded renderer framebuffer integration remains outstanding
