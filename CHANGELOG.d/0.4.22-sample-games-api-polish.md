## Added

- Added two larger, asset-free runnable 2D sample games: Breakout and Dodge Arena. They
  demonstrate complete gameplay loops using input, UI, scene tags, collision logic, progression,
  procedural spawning and cleanup instead of isolated subsystem snippets.
- Added additive creator-facing `Scene.require(name)`, `Scene.remove_many(...)`, and
  `Scene.remove_tagged(tag)` helpers with identity-safe bulk removal and clear missing-object
  diagnostics.
- Added focused documentation for the larger samples and scene helpers under `examples/README.md`.

## Compatibility

- Existing scene lookup/removal behavior is unchanged. The new helpers are additive in the 0.4.x
  API, and `Game.remove(...)` remains the preferred path when an individual object owns registered
  physics or UI subsystem state.
