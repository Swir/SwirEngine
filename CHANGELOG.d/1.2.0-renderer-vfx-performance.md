# SwirEngine 1.2 — renderer / VFX performance pass

- Added sequence-compatible streaming 2D render runs so repeatable scene lists no longer require a second outer frame-sized run tuple before drawing.
- Added bounded reuse of immutable sprite batch-state keys across frames while preserving adjacent-only batching and transparent draw order.
- Added an allocation-free fast path for already-valid immutable `Color.clamped()` values used by renderer/VFX hot paths.
- Removed per-sample `sorted()` list allocations from particle emission range sampling while preserving reversed-range behavior.
- Added deterministic regression gates covering render-run materialization, state-key reuse, color identity reuse and particle range compatibility.
- Added `tools/benchmark_renderer_vfx_framework.py` for local streamed/materialized frame-work and VFX measurements.
- No specific FPS uplift is claimed; CI guards deterministic reductions in repeated Python-side work, while host-dependent timings remain diagnostic.
