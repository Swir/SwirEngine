# SwirEngine 1.1.0 — standardized controller input

- add a public `GamepadSnapshot` model backed by GLFW's cross-platform standard gamepad mapping
- add deterministic connected-controller discovery, names and GUID snapshots
- add held / pressed / released gamepad button queries with Xbox/PlayStation-friendly aliases
- add normalized left/right stick helpers with configurable deadzones and post-deadzone range rescaling
- add trigger helpers normalized to creator-friendly `0.0 .. 1.0`
- add hot-plug connection/disconnection edge queries
- refresh controller state automatically once per normal `Game.run()` frame without changing keyboard/mouse behavior
- export the gamepad mapping constants and normalization helpers as stable public 1.x APIs
- add a runnable controller + keyboard-fallback example
- add regression coverage for mappings, aliases, deadzones, trigger normalization, hot-plug behavior, button edges and GLFW state shapes
- refresh README/PyPI documentation before publication and start the measurable SwirEngine 1.1 roadmap
- keep the historical 1.0 roadmap locked at 31/31 (100%)
