# 2D Renderer Power Pass

- keep `TileMap2D` fixed child pools for 1.x compatibility while marking child sprites as aggregate-managed so scene update/render-root scans do not visit every pooled child every frame
- cache scene render roots and rebuild them only when scene membership changes
- make tilemap transform synchronization dirty-driven so unchanged updates perform zero full-pool sprite-transform visits
- maintain `tile_count` incrementally in O(1) and keep a stable `children` tuple instead of allocating it repeatedly
- compute tilemap visibility from camera bounds and visit only locally visible/candidate cells rather than scanning the whole map
- add conservative camera culling for world-space rectangles and explicit-size sprites before batching
- replace per-batch Python float-list construction with a geometrically grown reusable NumPy staging buffer and buffer-protocol VBO upload
- expose 2D render-root, culled-object and tilemap candidate/visible diagnostics
- add CPU/locality regressions, a 192×192 tilemap benchmark, creator demo and a real Xvfb/software-OpenGL moving-camera production smoke
- verified benchmark contract: 36,864 authored cells, at most 943 viewport candidates in the CI workload, and zero full-pool transform visits across unchanged updates; elapsed timings remain diagnostics only and are not FPS claims
- preserve the existing `Game` and `TileMap2D` creator APIs; this milestone does not claim construction-time memory reduction or GPU tilemap instancing
