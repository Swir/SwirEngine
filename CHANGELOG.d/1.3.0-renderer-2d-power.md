# 2D Renderer Power Pass

- treat tilemap pooled sprites as aggregate-managed scene children while preserving fixed child pools and scene registration compatibility
- cache scene render roots so managed tile children do not enter the per-frame render sort
- skip managed child no-op updates and keep `TileMap2D` transform synchronization dirty-state driven
- make `TileMap2D.tile_count` O(1) and reuse the same `children` tuple
- convert camera viewports directly to local tile-cell bounds so render preparation scales with visible cells instead of total map size
- conservatively cull off-camera world-space rectangles and explicit-size sprites before draw preparation
- add a geometrically grown reusable NumPy sprite staging buffer and buffer-protocol VBO uploads
- add renderer/tilemap diagnostics for render roots, culls, local cell candidates and transform visits
- add CPU/locality regressions, benchmark, large moving-camera demo and a real Xvfb/software-OpenGL production smoke
- keep performance claims measurable and avoid synthetic FPS claims; tilemap construction memory remains explicitly outside this milestone
