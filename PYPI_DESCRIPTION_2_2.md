# SwirEngine 2.2.0

SwirEngine is a Python-first engine for complete 2D, 3D and multiplayer games. Version 2.2.0
extends the shipping runtime with production tools and visual creation workflows while preserving
the published 2.1 compatibility baseline.

## Included in 2.2

- runtime-backed material, shader, terrain, foliage, animation, particle/VFX and lighting tools;
- responsive UI authoring over the shipping retained UI toolkit;
- privacy-safe multiplayer diagnostics and capability-gated editor extensions;
- project-confined resources, deterministic serialization and relocated export validation;
- explicit 64-bit CPython 3.10–3.14 qualification on the maintained hosted-runner matrix.

The authoritative availability and source identity for this version are the package index metadata,
the immutable `v2.2.0` tag and the corresponding GitHub Release provenance. Repository roadmaps
and transient candidate status do not override those public records.

Documentation, migration guidance and source are available from the
[SwirEngine repository](https://github.com/Swir/SwirEngine).
